# Аудит исходной версии

Исходная точка: `Mirrorby/f1demo`, main, commit `7df77d0`. В репозитории один `index.html` (1145 строк), без backend, тестов и конфигурации сборки. Корневой файл оставлен без изменений как работоспособная историческая версия. Worker раздаёт только `public/`; исходная витрина Google Sheets в его assets не входит.

Сохранены дизайн карточек и модальных окон, категории, валюты, процентная скидка, наличие/предзаказ, выбор вариантов, корзина, карусель, свайпы и увеличение фотографий, контакты и подтверждение заказа. HTML, CSS и JS выделены в отдельные файлы. Доставка теперь настраивается для каждого магазина, без привязки общего движка к Алматы, QazPost и CDEK.

Подтверждённые дефекты исходника:

- Ошибка Apps Script перехватывалась, после чего генерировался запасной номер и показывалось успешное подтверждение. Теперь подтверждение требует успешного ответа API с ID сохранённого заказа.
- Товар в наличии без размеров нельзя было добавить. Теперь каждый товар имеет минимум один вариант, в том числе «Без вариантов».
- Цены и сумма исходили из браузера. Теперь сервер использует текущие цены, скидку и варианты из D1. Несовпадение с ценой в корзине возвращает 409.
- Выбор количества не учитывал общий остаток. Теперь списание остатков и запись заказа выполняются атомарно; конкурентные запросы не продают последнюю единицу дважды.
- Пользовательские строки вставлялись в HTML и inline JavaScript без полной защиты. Теперь текст экранируется, а обработчики динамических категорий и вариантов используют числовые индексы.
- При ошибке загрузки CSV показывался чужой встроенный демокаталог. Теперь ошибка загрузки конкретного магазина видна покупателю.
- CSV-парсер не поддерживал многострочные поля. В рабочем приложении CSV отсутствует.

Приложенный XLSX содержит 4 непустых товарных строки, 3 категории, цены KZT/RUB, остатки XS–XXL, 20% скидку у одного товара, предзаказ и лист настроек. Исторические заказы и контактные данные не включены в тестовые примеры. `scripts/import_xlsx.py` переносит каталог и основные тексты в JSON. Фото по умолчанию исключены; включение требует `--include-images` и права на их использование. Это одноразовый импорт, приложение не обращается к Google Sheets или Apps Script.

Новый источник данных: D1. Изображения загружаются в R2; внешние HTTPS-фото можно использовать по договорённости с владельцем. Для полного отказа от хранения фото в Drive загрузите оригиналы через Mini App.
