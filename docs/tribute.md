# Tribute: оплата услуг Catalog Factory

Интеграция принимает платежи владельцев магазинов за ваши услуги. Платежи покупателей за товары в их витринах — отдельная задача. Фиксированные тарифы и автоматические списания не включены: вы задаёте сумму каждого разового счёта.

## Подключение

1. В @tribute подключите активный **Tribute Shop** с приёмом карт. Обычный цифровой товар и OnlyStars-магазин не подходят для этой интеграции. Если раздел Shops отсутствует, уточните доступ к Shop API у поддержки Tribute.
2. В Cloudflare → Workers → catalog-factory → Settings → Variables and Secrets добавьте **TRIBUTE_API_KEY** как Secret. Ключ не вставлять в чат, исходники или браузерную панель.
3. Добавьте **TRIBUTE_SHOP_ID** как текстовую переменную: числовой ID нужного магазина. API GET /api/v1/shops показывает доступные активные магазины. Ключ и ID должны принадлежать одному магазину.
4. В настройках этого Tribute Shop задайте callback/webhook:
   https://catalog-factory.nikita-karpof.workers.dev/api/tribute/webhook
   Если другие продукты уже используют другой webhook, сохраните их маршрутизацию: проверьте callbackUrl именно этого Shop через API.
5. Примените миграции D1 и разверните код. Повторно нажмите «Настроить Telegram-бота» в /platform для добавления /pay в список команд.
6. Откройте /platform: проверка Tribute должна показать активный магазин, приём карт и совпадение callback.

## Выставить счёт

Сначала подключите Telegram-владельца магазина. В панели /platform раскройте «Оплата Tribute», заполните понятные клиенту название и описание, сумму и валюту EUR / USD / RUB. Счёт появляется у клиента в /pay и по кнопке «Оплата / Payments».

Суммы хранятся в целых центах/копейках. API:
POST /api/platform/stores/{storeId}/invoices
Authorization: Bearer <platform key>

Пример тела:
```json
{
  "id": "11111111-1111-4111-8111-111111111111",
  "amountMinor": 10000,
  "currency": "eur",
  "title": "Online store setup",
  "description": "Setup of your online store with Telegram management."
}
```

UUID создаётся на клиенте и служит защитой от повторного создания. Повтор с теми же параметрами возвращает тот же счёт; изменение параметров требует нового UUID. Валюты выбираются для счёта, а не автоматически по языку пользователя.

## Подтверждение и восстановление

Оплата засчитывается только после подписанного shop_order с paid, точной суммой, валютой и совпадающими Shop/UUID/клиентом, либо после ручной сверки с авторизованным Tribute API. Переход по successUrl и нажатие кнопки не подтверждают оплату. Редирект возвращает клиента к /pay.

Webhook использует HMAC-SHA256 от исходного тела с ключом TRIBUTE_API_KEY. Повторные доставки не создают повторных зачислений. Уведомления клиенту сохраняются в очереди; сбой Telegram не отменяет подтверждённую оплату. Повторные отправки идут существующим расписанием Worker.

Если при создании оборвалась связь, счёт получает review. Автоматического повторного POST в Tribute нет: это может создать второй счёт. Найдите заказ в кабинете Tribute по комментарию Catalog Factory <локальный UUID>, нажмите «Сверить с Tribute» и укажите его remote UUID. Сверка проверяет магазин, комментарий, сумму, валюту и отсутствие повторных списаний. Подписанный webhook также может восстановить связь с потерянным ответом.

shop_order_refunded регистрируется как refund_reported: это сообщение о возврате, в том числе частичном. Поздний исходный paid не стирает возврат. Автоматическое отключение/активация сайта, возврат денег и подписки этой интеграцией не выполняются.

Список счетов доступен только платформе; /pay показывает только счета Telegram-пользователя, которому они выставлены. При передаче магазина история старых счетов остаётся у исходного плательщика. Демо со счетами сохраняется для финансовой истории и не удаляется обычной кнопкой удаления.

## Проверка перед продажами

После настройки нужны реальная небольшая оплата, проверка подписанного webhook и появления paid в панели и /pay, затем проверка вывода средств на выбранный вами способ. Доступность оплаты зависит от магазина Tribute и банка плательщика; обещание «любой платёж из любой страны» не даётся.
